## Linking directly to a course

Expand a course in the catalogue and select **Share** to copy its direct link
to your clipboard, or copy the URL from the address bar.
If clipboard access is unavailable or denied, a selected link field appears for manual copying.
The URL uses the course filename without `.md` as its fragment, for example
`https://sayedimac.github.io/coursecontent/#ab-620`.
Opening the link selects the course's area and expands its details.
Existing area links such as `#area-0` continue to work.

A flask icon beside a course title indicates that a hands-on labs link is available.
