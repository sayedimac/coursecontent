Builds practical skills for developing, deploying, and managing agentic AI systems within GitHub-based software development workflows. Covers agent architecture, tools and environments, memory and state, evaluating and optimizing agent output, governance and guardrails, and coordinating multi-agent systems, with GitHub as the control plane.
